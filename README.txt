# Amor em Site — Criador Real

Abra `index.html`, preencha os dados, selecione fotos e uma música e clique em **Gerar meu site completo**.

O criador baixa um único arquivo `meu-site-presente.html` com os textos, fotos e áudio incorporados.

Para publicar o presente:
1. Crie uma pasta/repositório no GitHub.
2. Envie `meu-site-presente.html`.
3. Renomeie para `index.html` se quiser abrir diretamente na raiz do Pages.
4. Ative o GitHub Pages.
